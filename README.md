# rural-net
A Digital Information Platform for Rural Communities using HTML, CSS, JavaScript and Python Flask.
## 🚀 Projects

### 🌾 Rural Net – Digital Information Platform

A digital information platform designed to support rural communities by providing useful information and services through a web-based application.

**Features:**
- 🌐 Rural community information
- 🌦️ Weather information
- 📊 Market-related information
- 👨‍🌾 Farmer-focused resources
- 🔐 User authentication
- 📱 Responsive web interface

**Technologies Used:**
- HTML
- CSS
- JavaScript
- Python
- Flask
